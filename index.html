⚠️ 소리로 찾는 도구예요 — 대화·교전·바람 소리가 있으면 틀릴 수 있어요

⚠️ 이 도구는 화물을 드래그할 때 나는 소리로 템을 찾아요. 화면은 격자 위치만 봐요.

디코·게임 보이스 같은 유저 간 대화, 교전 소리, 바람·환경음이 같이 들리면 소리를 못 찾거나 틀릴 수 있어요.

  3. VB-CABLE로 게임 소리만 사이트에 넣으세요.
  4. 조용할 때 화물을 다시 드래그해 확인하고, 틀리면 「이 화물 리셋」을 누르세요.

    화물 격자 쓰는 법

    1. 화면+소리 공유: 「화면 공유로 시스템 소리 가져오기」를 누르고 아브아 화면(전체 화면 권장)을 고른 뒤 「시스템 오디오도 공유」를 켜세요. 「화면도 읽기」가 켜져 있어야 합니다.
    2. 상인 화물창 열기: 전장 상인의 구매 화면을 열면 오른쪽 화물 격자를 자동으로 찾습니다.
    3. 스크롤 끝까지: 스크롤바를 맨 아래까지 천천히 내려서 모든 줄이 기록되게 하세요.
    4. 화물에 마우스 올리기: 마우스를 올리면 어느 화물인지 표시됩니다(노란 테두리).
    5. 한 번 드래그: 화물을 한 번 드래그하면 소리로 물품을 맞혀 그 칸에 이름·가격·확률을 넣습니다.

    자동 인식이 틀리면 위 「칸 크기 지정」에서 크기를 고르고 격자 칸을 눌러 직접 고치세요. 화물을 누르면 다음 소리 결과를 그 화물에 넣습니다. 화면은 이 브라우저 안에서만 처리하고 어디에도 보내지 않습니다.

    2. 감시

    F8과 단축키는 이 페이지(또는 작은 창)에 포커스가 있을 때만 작동합니다. 게임 중에는 자동 감지를 켜 두세요.

    ❓ 사용법 / 설정 방법
    

    1. 기본 사용 순서
      

    1. 화면 공유 시작: 「화면 공유 + 소리 연결」을 누르고 게임 화면(「전체 화면」 권장)을 고른 뒤 「시스템 오디오도 공유」를 켜세요.
      2. 

    2. 감시 시작: 「▶ 감시 시작 (F8)」을 누르세요. 「작은 창으로 띄우기」로 게임 위에 띄워 둘 수 있어요.
      3. 

    3. 상인 화물 화면 열기: 화물 격자를 자동으로 찾아요. 스크롤을 끝까지 천천히 내려 모든 줄을 기록하세요.
      4. 

    4. 화물 드래그: 화물을 드래그하면 소리로 물품을 판별해 그 칸에 표시해요. 여러 번 드래그하면 결과를 합쳐요.
      5. 

    5. 격자 표시 뜻
        

      • 빨간 테두리 = 빨템이 나올 수 있는 화물
        • 

      • ✓ = 확인한 화물
        • 

      • ✓빨강 = 그 소리를 내는 빨템이 하나뿐이라 빨템으로 확정
        • 

      • 이름표는 같은 화물을 다시 검색하기 전까지 계속 남아요.
      6. 

    6. 기록 — 확인한 화물: 확인한 화물의 시간·위치·크기·이름표가 쌓여요.
      7. 

    7. 리셋: 잘못 잡혔으면 「이 화물 리셋」 또는 「전체 리셋」을 누르세요.
      8. 

    8. 감도 −/+: 1~7 (기본 4). 소리를 놓치면 +, 엉뚱한 소리에 반응하면 −.
      9. 

    9. 증폭 ×1/×2/×4/×8: 게임 소리가 작아 미터가 거의 안 움직일 때만 올리세요.
      10. 

    10. 🧪 테스트 란: 「테스트 모드 켜기」 → 창고에서 「사운드 테스트 시작」 → 아이템을 옮겨 보세요. 격자와 따로 동작해요. 안 되면 「진단 글 복사」로 보내 주세요.

    2. 팀원 목소리 분리하기 (디스코드·게임 보이스)

    화면 공유 소리는 PC 소리 전체를 받아서 목소리도 같이 들어가요. 게임 소리만 받게 나누면 가장 확실해요.
    

    1. 간단한 방법: 디스코드(또는 게임 보이스) 출력을 다른 장치(예: 헤드셋)로 바꾸고, 사이트 「소리 소스」를 「입력 장치 직접 선택」으로 바꿔 게임 소리만 오는 장치를 고르세요.
      2. 

    2. VB-CABLE 쓰기 (장치가 하나뿐일 때, 무료)
        

      1. vb-audio.com/Cable에서 받아 설치하고 PC를 다시 켜세요.
        2. 

      2. Windows 설정 > 시스템 > 소리 > 볼륨 믹서(앱 볼륨 및 장치 기본 설정)에서 게임 exe의 출력을 CABLE Input으로 바꾸세요.
        3. 

      3. 사이트에서 「입력 장치 직접 선택」 → CABLE Output을 고르세요.
        4. 

      4. 내 귀로도 들으려면: 제어판 > 소리 > 녹음 탭 > CABLE Output 속성 > 수신 대기 > 「이 장치로 듣기」 체크 → 재생 장치를 내 헤드셋으로 고르세요.
      3. 

    3. 급할 때: 화물을 확인하는 몇 초 동안만 보이스 음량을 잠깐 낮추세요.
    

    3. 바람·환경음 줄이기
      

    • 게임 소리 설정에서 환경음·음악·보이스는 낮추고 효과음은 높이세요.
      • 

    • 사이트 감도를 1~2칸 내리고(−), 증폭은 ×1~×2로 두세요.
    

    4. 캡처보드·오디오 인터페이스(오인페) 사용자 / 테스트 2단계에서 막힐 때

    맨 위 「1. 소리 가져오기」의 「소리 소스」를 「입력 장치 직접 선택」으로 바꾸고 장치를 고르세요. ★ 표시는 게임 소리 경로로 보이는 장치예요.
