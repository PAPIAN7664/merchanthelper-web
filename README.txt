행상 도우미 웹 (MerchantHelper 웹 포트)
=====================================
원작: 烟火 (A1Chao) — https://github.com/A1Chao/MerchantHelper
이 폴더는 원작 오픈소스판(--no-vision, 소리 인식만)을 브라우저로 옮긴 비공식 포트입니다.
学习交流用，禁止商业用途 — 학습·교류 전용, 상업적 이용 금지. 원작자 표기를 지우지 마세요.
assets/ 의 아이콘·효과음·물품 데이터는 원작 저장소 그대로이며 저작권은 게임 권리자에게 있습니다.
(원작 README / THIRD-PARTY-LICENSES 사본: assets/ORIGINAL-*.md)

실행
----
1) index.html 을 Chrome 또는 Edge로 더블클릭해서 엽니다. (서버 없이 file:// 로 동작)
   또는 이 폴더에서:  python -m http.server 8000  →  http://localhost:8000
2) 「화면 공유로 시스템 소리 가져오기」 → 「전체 화면」 탭 → 「시스템 오디오도 공유」 켜기 → 공유
   (또는 스테레오 믹스 / VB-CABLE 같은 입력 장치를 골라 「이 장치 사용」)
3) 「감시 시작」 또는 F8 (이 페이지에 포커스가 있을 때만). 게임 중에는 「효과음 자동 감지」가 인식을 시작합니다.
4) 「작은 창으로 띄우기」로 후보 패널을 항상 위 작은 창으로 띄울 수 있습니다 (전체 화면 독점 모드 위에는 안 뜸 → 게임을 「테두리 없는 창」 모드로).
